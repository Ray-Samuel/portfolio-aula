# Portfólio

Projeto de desenvolvimento de um site de portfólio pessoal, criado utilizando HTML e CSS.

## Estrutura do projeto

```text
portfolio/
│
├── css/
│   ├── responsivo.css
│   └── style.css
│
├── images/
│
└── index.html
```

## Tecnologias utilizadas

- HTML5
- CSS3

## Arquivos

- **index.html:** estrutura principal do site.
- **css/style.css:** estilos e personalização visual do site.
- **css/responsivo.css:** ajustes de layout para diferentes tamanhos de tela.
- **images/:** imagens utilizadas no projeto.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
